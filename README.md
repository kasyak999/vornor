# О проекте
**VORNOR** - это торговый бот, который помогает минимизировать риски и повысить прибыль за счёт автоматизации стратегии усреднения позиции (DCA — Dollar Cost Averaging).
Он анализирует рыночную динамику, выставляет ордера на покупку и продажу, а также при падении цены автоматически докупает актив, снижая среднюю цену входа и тем самым уменьшая порог для выхода в прибыль.

🚀 Основные функции
- Автоматическая покупка криптовалюты по заданным параметрам.
- Установка ордеров на продажу с заданным процентом прибыли.
- Докупка при падении курса для усреднения средней цены покупки.
- Гибкая настройка стратегии — шаг докупки, максимальное количество усреднений.

Интеграция с популярной биржой через API Bybit.

📊 Преимущества
- Снижает риски при волатильных рынках.
- Автоматизирует рутинные торговые операции.
- Работает 24/7 без участия трейдера.
- Позволяет зарабатывать даже при боковом или падающем рынке.
- Ваши деньги остаются у вас и нет никаких посредников.

## Стек технологий
Проект использует следующие основные компоненты:

Язык
- Python 3.13

Backend
- FastAPI — высокопроизводительный backend-фреймворк
- PostgreSQL — основная реляционная база данных
- Redis — in-memory хранилище, используется как брокер сообщений
- Celery — асинхронные фоновые задачи
- Flower — веб-мониторинг Celery задач
- SQLAdmin — административная панель на основе SQLAlchemy

Инфраструктура
- Docker / Docker Compose — контейнеризация и оркестрация сервисов
